# Pollution, Novel Entities, and Long-Run Development

Advanced code workflows for the article on pollution, novel entities, and long-run development.

## Included workflows

- Python:
  - pollution and novel-entities development risk scoring
  - governance, monitoring, and remediation diagnostics
- R:
  - cross-region and cross-territory pollution summaries
  - toxic inequality and systemic burden analysis
- SQL:
  - pollution-risk registry
  - waste, exposure, and governance logs
  - public-health and toxicity dashboards
- Go:
  - lightweight pollution-risk scoring service
- Rust:
  - validation utility for pollution and novel-entities records
- Embedded C:
  - optional low-resource monitoring signal node
- C++:
  - optional local pollution-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and burden analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional monitoring signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
