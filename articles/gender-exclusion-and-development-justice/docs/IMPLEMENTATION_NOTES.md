# Implementation Notes

This module is designed around five linked gender-justice questions:

1. Which settings face the greatest gap between formal equality and substantive freedom?
2. Where do care burden and violence most sharply weaken capability formation?
3. Which territories show the strongest institutional exclusion from power and property?
4. Where are governance and transition capacity weakest relative to gendered burden?
5. How can education, autonomy, participation, and safety be tracked together?

Suggested workflow:
- Validate raw CSVs with Rust.
- Run Python risk-scoring pipelines.
- Run R comparative and burden analysis.
- Use SQL tables and views to maintain gender, governance, and burden registries.
- Use Go for lightweight gender-risk scoring integration.
