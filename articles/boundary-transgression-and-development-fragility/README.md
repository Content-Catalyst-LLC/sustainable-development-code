# Boundary Transgression and Development Fragility

This module contains the code workflows referenced in the article on boundary transgression and development fragility.

## Included workflows

- Python: boundary pressure, ecological overshoot, and development fragility scoring
- R: boundary pressure and ecological fragility analysis
- SQL: ecological pressure registry, transgression event logs, and dashboard views
- Rust: validation utility for ecological fragility input records
- Go: lightweight ecological fragility evaluation service
- Embedded C: low-level infrastructure stress monitoring
- C++: edge-side ecological fragility and resilience scoring

## Folder layout

- `python/`: fragility scoring and boundary-pressure analysis
- `r/`: comparative and longitudinal ecological fragility analysis
- `sql/`: schema, event logs, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight fragility evaluation service
- `c/`: embedded monitoring and threshold logic
- `cpp/`: edge resilience and fragility scoring
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
