# International Organizations and Global Development Governance

Advanced code workflows for the article on international organizations and global development governance.

## Included workflows

- Python:
  - global development governance capacity scoring
  - fragmentation, legitimacy, and implementation diagnostics
- R:
  - cross-country and cross-domain multilateral summaries
  - finance and institutional variation analysis
- SQL:
  - multilateral governance registry
  - finance, standards, and implementation logs
  - legitimacy and fragmentation dashboards
- Go:
  - lightweight global-governance scoring service
- Rust:
  - validation utility for multilateral governance records
- Embedded C:
  - optional low-resource coordination signal node
- C++:
  - optional local multilateral-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and institutional analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional coordination signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
