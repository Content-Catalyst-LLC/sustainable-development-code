# Geography of Global Poverty

Advanced code workflows for the article on spatial poverty, territorial exclusion, and sustainable development.

## Included workflows

- Python:
  - geographic-poverty risk scoring
  - spatial exclusion and service-access diagnostics
- R:
  - cross-region and cross-territory poverty summaries
  - rural exposure, urban informality, and governance-pressure analysis
- SQL:
  - geographic-poverty registry
  - territorial pressure and governance logs
  - spatial poverty dashboards
- Go:
  - lightweight geographic-poverty risk scoring service
- Rust:
  - validation utility for geographic-poverty records
- Embedded C:
  - optional low-resource territorial signal node
- C++:
  - optional local geographic-poverty risk scorer
