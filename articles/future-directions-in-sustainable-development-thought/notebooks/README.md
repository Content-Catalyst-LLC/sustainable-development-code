# Notebook guidance

Use notebooks for exploration and communication, not as the only source of analytical logic.

Recommended workflow:

1. Run `bash bash/run_all.sh`.
2. Inspect `outputs/future_development_viability_scores.csv`.
3. Review threshold flags before interpreting composite rankings.
4. Compare country-level trends in `outputs/development_viability_panel_scored_r.csv`.
5. Use the SQLite dashboard for reproducible query-driven summaries.
