# Beyond GDP Development: Measuring Prosperity as a Systems Outcome

Code workflows and analytical scaffolding for modeling prosperity beyond GDP using multi-dimensional systems indicators.

## Included workflows

- Python:
  - multi-dimensional prosperity scoring
  - GDP distortion-gap analysis
- R:
  - systems-outcome comparison across country/development profiles
- SQL:
  - optional registry schema for development-indicator panels
- Docs:
  - implementation notes and metric-architecture guidance

## Core idea

GDP remains useful, but it should be treated as one component of a wider measurement architecture that includes health, education, institutions, ecology, and distribution.
