# Innovation, Technology Transfer, and Leapfrogging

This module contains the code workflows referenced in the article on innovation, technology transfer, and leapfrogging.

## Included workflows

- Python: absorptive-capacity scoring, leapfrogging readiness, and technology-dependence risk analysis
- R: innovation inequality, ecosystem benchmarking, and diffusion pattern analysis
- SQL: technology registry, standards tracking, transfer agreements, and dependency audits
- Go: lightweight readiness scoring service
- Rust: validation utility for transfer and capability records
- Embedded C: optional low-resource edge deployment example
- C++: optional edge-side interoperability and resilience scoring

## Folder layout

- `python/`: scoring, readiness, and dependence diagnostics
- `r/`: ecosystem and distribution analysis
- `sql/`: schema, transfer logs, standards, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight readiness scoring service
- `c/`: optional embedded deployment logic
- `cpp/`: optional edge interoperability scoring
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
