# Gender, Exclusion, and Development Justice

Advanced code workflows for the article on gender, exclusion, and development justice.

## Included workflows

- Python:
  - gender-exclusion and development-justice risk scoring
  - care burden, violence, and institutional-gap diagnostics
- R:
  - cross-region and cross-territory gender summaries
  - capability-gap, care-burden, and governance-risk analysis
- SQL:
  - gender-risk registry
  - capability, security, and governance logs
  - justice dashboards
- Go:
  - lightweight gender-justice risk scoring service
- Rust:
  - validation utility for gender-justice records
- Embedded C:
  - optional low-resource inclusion signal node
- C++:
  - optional local gender-risk scorer
