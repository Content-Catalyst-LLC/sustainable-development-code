# Scenario Planning for Sustainable Futures

This module contains the code workflows referenced in the article on scenario planning for sustainable futures.

## Included workflows

- Python: scenario matrix generation and robustness scoring
- R: scenario panel and adaptive-capacity analysis
- SQL: scenario registry, pathway decision logging, and robustness dashboard views
- Rust: validation utility for scenario input records
- Go: lightweight pathway evaluation service
- Embedded C: low-level infrastructure monitoring for uncertain operating conditions
- C++: edge-side resilience scoring for infrastructure systems

## Folder layout

- `python/`: scenario generation and robustness analysis
- `r/`: comparative and longitudinal scenario analysis
- `sql/`: schema, decision logs, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight scenario evaluation service
- `c/`: embedded monitoring and fail-safe logic
- `cpp/`: edge resilience scoring logic
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
