# Why Institutions Matter for Sustainable Development

Advanced code workflows for the article on institutions and sustainable development.

## Included workflows

- Python:
  - institutional capacity and delivery-system scoring
  - fragmentation, trust, and implementation diagnostics
- R:
  - cross-country and cross-domain institutional summaries
  - trust and delivery variation analysis
- SQL:
  - institutional-capacity registry
  - delivery and accountability logs
  - trust and fragmentation dashboards
- Go:
  - lightweight institutional-capacity scoring service
- Rust:
  - validation utility for institutional records
- Embedded C:
  - optional low-resource delivery signal node
- C++:
  - optional local institutional-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and delivery analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional delivery signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
