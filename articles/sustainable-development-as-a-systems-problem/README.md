# Sustainable Development as a Systems Problem

Advanced code workflows for the article on sustainable development as a systems problem.

## Included workflows

- Python:
  - systems-fragility and interaction-risk scoring
  - feedback and coordination diagnostics
- R:
  - cross-region and cross-territory systems summaries
  - interdependence, delay, and governance-capacity analysis
- SQL:
  - systems-problem registry
  - interaction, coordination, and governance logs
  - systems dashboards
- Go:
  - lightweight systems-fragility scoring service
- Rust:
  - validation utility for systems-risk records
- Embedded C:
  - optional low-resource interaction signal node
- C++:
  - optional local systems-fragility scorer
