# Implementation Notes

This module is designed around five linked policy-coherence questions:

1. Which settings face the greatest interaction pressure from trade-offs and spillovers?
2. Where are synergy opportunities present but unrealised because of fragmented governance?
3. Which territories show the strongest cross-sector and cross-scale coordination gaps?
4. Where are sequencing and review capacity weakest relative to policy ambition?
5. How can spillovers, alignment, and institutional coherence be tracked together?

Suggested workflow:
- Validate raw CSVs with Rust.
- Run Python risk-scoring pipelines.
- Run R comparative and burden analysis.
- Use SQL tables and views to maintain policy, governance, and burden registries.
- Use Go for lightweight policy-coherence risk scoring integration.
