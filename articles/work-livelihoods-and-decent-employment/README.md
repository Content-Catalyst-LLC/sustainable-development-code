# Work, Livelihoods, and Decent Employment

Advanced code workflows for the article on work, livelihoods, and decent employment.

## Included workflows

- Python:
  - work, livelihoods, and decent-employment risk scoring
  - labour fragility and protection diagnostics
- R:
  - cross-region and cross-territory work summaries
  - informality, exclusion, and governance gap analysis
- SQL:
  - work-risk registry
  - livelihood, rights, and governance logs
  - employment dashboards
- Go:
  - lightweight decent-employment risk scoring service
- Rust:
  - validation utility for work and livelihoods records
- Embedded C:
  - optional low-resource labour signal node
- C++:
  - optional local labour-risk scorer
