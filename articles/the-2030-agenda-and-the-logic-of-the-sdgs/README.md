# The 2030 Agenda and the Logic of the SDGs

Advanced code workflows for the article on the 2030 Agenda and the logic of the SDGs.

## Included workflows

- Python:
  - SDG-governance and agenda-risk scoring
  - implementation and monitoring diagnostics
- R:
  - cross-region and cross-territory SDG logic summaries
  - integration, review, and governance-risk analysis
- SQL:
  - SDG-logic registry
  - implementation, monitoring, and governance logs
  - agenda dashboards
- Go:
  - lightweight SDG-governance risk scoring service
- Rust:
  - validation utility for SDG-governance records
- Embedded C:
  - optional low-resource monitoring signal node
- C++:
  - optional local SDG-governance risk scorer
