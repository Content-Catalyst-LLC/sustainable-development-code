# Poverty, Deprivation, and Multidimensional Development

Advanced code workflows for the article on poverty, deprivation, and multidimensional development.

## Included workflows

- Python:
  - multidimensional poverty and deprivation risk scoring
  - deprivation-bundle and public-goods diagnostics
- R:
  - cross-region and cross-territory poverty summaries
  - poverty-bundle, child-vulnerability, and governance-risk analysis
- SQL:
  - multidimensional-poverty registry
  - deprivation, climate, and governance logs
  - poverty dashboards
- Go:
  - lightweight multidimensional-poverty scoring service
- Rust:
  - validation utility for multidimensional-poverty records
- Embedded C:
  - optional low-resource deprivation signal node
- C++:
  - optional local poverty-risk scorer
