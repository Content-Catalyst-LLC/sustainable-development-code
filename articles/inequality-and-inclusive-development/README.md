# Inequality and Inclusive Development

Advanced code workflows for the article on inequality and inclusive development.

## Included workflows

- Python:
  - inequality and inclusion risk scoring
  - capability-gap and institutional-access diagnostics
- R:
  - cross-region and cross-territory inclusion summaries
  - inequality burden and governance gap analysis
- SQL:
  - inclusion-risk registry
  - capability, public-goods, and governance logs
  - inclusion dashboards
- Go:
  - lightweight inclusion-risk scoring service
- Rust:
  - validation utility for inclusion-risk records
- Embedded C:
  - optional low-resource inclusion signal node
- C++:
  - optional local inclusion-risk scorer
