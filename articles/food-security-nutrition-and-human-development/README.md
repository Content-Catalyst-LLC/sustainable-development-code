# Food Security, Nutrition, and Human Development

Advanced code workflows for the article on food security, nutrition, and human development.

## Included workflows

- Python:
  - food-security and human-development risk scoring
  - affordability, fragility, and nutrition diagnostics
- R:
  - cross-region and cross-territory food summaries
  - inequality, affordability, and governance gap analysis
- SQL:
  - food-risk registry
  - nutrition, fragility, and governance logs
  - diet dashboards
- Go:
  - lightweight food-risk scoring service
- Rust:
  - validation utility for food-security and nutrition records
- Embedded C:
  - optional low-resource nutrition signal node
- C++:
  - optional local food-risk scorer
