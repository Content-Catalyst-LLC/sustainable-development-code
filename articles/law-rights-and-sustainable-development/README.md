# Law, Rights, and Sustainable Development

Advanced code workflows for the article on law, rights, and sustainable development.

## Included workflows

- Python:
  - legal protection and remedy capacity scoring
  - exclusion, accountability, and enforceability diagnostics
- R:
  - cross-country and cross-domain rights summaries
  - justice access and exclusion analysis
- SQL:
  - legal protection registry
  - remedy and review logs
  - rights and accountability dashboards
- Go:
  - lightweight legal-capacity scoring service
- Rust:
  - validation utility for law-and-rights records
- Embedded C:
  - optional low-resource legal-access signal node
- C++:
  - optional local legal-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and justice analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional legal-access signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
