# Business as Usual vs Sustainable Development

Advanced code workflows for the article on incumbent growth systems, transition risk, and sustainable development.

## Included workflows

- Python:
  - business-as-usual risk scoring
  - transition-readiness diagnostics
- R:
  - cross-region and cross-territory transition summaries
  - ecological constraint, inclusion, and governance-pressure analysis
- SQL:
  - transition-risk registry
  - system pressure and governance logs
  - business-as-usual dashboards
- Go:
  - lightweight transition-risk scoring service
- Rust:
  - validation utility for transition-risk records
- Embedded C:
  - optional low-resource transition signal node
- C++:
  - optional local transition-risk scorer
