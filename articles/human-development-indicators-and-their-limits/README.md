# Human Development Indicators and Their Limits

Advanced code workflows for the article on human development indicators and their limits.

## Included workflows

- Python:
  - human development indicator diagnostic scoring
  - coverage, robustness, and hidden-burden diagnostics
- R:
  - cross-region and cross-territory indicator summaries
  - inequality signal and data-quality gap analysis
- SQL:
  - indicator-risk registry
  - attainment, burden, and methodology logs
  - interpretation dashboards
- Go:
  - lightweight indicator-risk scoring service
- Rust:
  - validation utility for indicator and development-risk records
- Embedded C:
  - optional low-resource data signal node
- C++:
  - optional local indicator-risk scorer
