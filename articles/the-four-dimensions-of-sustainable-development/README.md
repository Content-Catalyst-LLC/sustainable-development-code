# The Four Dimensions of Sustainable Development

Advanced code workflows for the article on prosperity, inclusion, ecology, governance, and sustainable development.

## Included workflows

- Python:
  - four-dimensions risk scoring
  - dimensional fragility diagnostics
- R:
  - cross-region and cross-territory dimensional summaries
  - governance and long-run viability analysis
- SQL:
  - four-dimensions registry
  - balance and governance logs
  - dimensional dashboards
- Go:
  - lightweight four-dimensions risk scoring service
- Rust:
  - validation utility for four-dimensions records
- Embedded C:
  - optional low-resource dimensional signal node
- C++:
  - optional local four-dimensions risk scorer
