# Implementation Notes

This module is designed around five linked intergenerational questions:

1. Which settings are transferring the largest burdens into the future?
2. Where do ecological degradation and institutional erosion most sharply weaken long-term stewardship?
3. Which territories show the strongest gaps in future representation and precautionary planning?
4. Where are resilience-preservation and governance capacity weakest relative to delayed risk?
5. How can burden transfer, stewardship capacity, and justice exposure be tracked together?

Suggested workflow:
- Validate raw CSVs with Rust.
- Run Python risk-scoring pipelines.
- Run R comparative and burden analysis.
- Use SQL tables and views to maintain intergenerational, governance, and burden registries.
- Use Go for lightweight intergenerational-risk scoring integration.
