# Corruption, Accountability, and Institutional Trust

Advanced code workflows for the article on corruption, accountability, and institutional trust.

## Included workflows

- Python:
  - corruption risk and institutional integrity scoring
  - capture, accountability, and visibility diagnostics
- R:
  - cross-country and cross-domain integrity summaries
  - trust and service-distortion analysis
- SQL:
  - integrity registry
  - accountability and complaint logs
  - procurement and risk dashboards
- Go:
  - lightweight integrity scoring service
- Rust:
  - validation utility for corruption and accountability records
- Embedded C:
  - optional low-resource integrity signal node
- C++:
  - optional local corruption-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and trust analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional integrity signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
