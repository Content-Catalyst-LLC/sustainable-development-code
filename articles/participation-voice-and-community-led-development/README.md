# Participation, Voice, and Community-Led Development

Advanced code workflows for the article on participation, voice, and community-led development.

## Included workflows

- Python:
  - participation and community-led development scoring
  - representation, accountability, and tokenism diagnostics
- R:
  - cross-country and cross-domain participation summaries
  - local governance and exclusion analysis
- SQL:
  - participation registry
  - grievance and accountability logs
  - representation and uptake dashboards
- Go:
  - lightweight participation-quality scoring service
- Rust:
  - validation utility for participation and accountability records
- Embedded C:
  - optional low-resource civic feedback node
- C++:
  - optional local participation signal scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and exclusion analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional civic feedback node logic
- `cpp/`: optional local signal scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
