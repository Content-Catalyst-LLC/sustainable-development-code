# Implementation Notes

This module is designed around five linked questions:

1. How far does GDP diverge from a broader systems-outcome measure of prosperity?
2. Which territories show the largest gap between output growth and durable wellbeing?
3. How much do institutions, ecology, and inequality alter the development picture?
4. Which cases appear strong by GDP but weak by systems outcome?
5. How should development dashboards be structured to reduce metric distortion?

## Metric architecture
GDP should be interpreted as one signal inside a wider prosperity framework, not as a master measure.

## Caution
All indicator weights in the Python workflow are illustrative and should be adapted to the user’s analytical purpose.
