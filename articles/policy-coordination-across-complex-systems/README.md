# Policy Coordination Across Complex Systems

Advanced code workflows for the article on policy coordination across complex systems.

## Included workflows

- Python:
  - policy coherence and spillover scoring
  - feedback, delay, and coordinated-transition diagnostics
  - trade-off and synergy scenario analysis
- R:
  - cross-country and cross-sector coherence summaries
  - multilevel governance and territorial mismatch analysis
- SQL:
  - policy instrument registry
  - agency mandate and coordination logs
  - spillover, trade-off, and coherence dashboards
- Go:
  - lightweight policy-coherence scoring service
- Rust:
  - validation utility for policy, mandate, and coordination records
- Embedded C:
  - optional low-resource infrastructure-signal node
- C++:
  - optional local system event and coordination alert scoring

## Folder layout

- `python/`: scoring, diagnostics, and scenario workflows
- `r/`: comparative summaries and mismatch analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional embedded system-signal logic
- `cpp/`: optional local event and alert scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: notes and implementation guidance
