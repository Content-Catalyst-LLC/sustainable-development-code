# Energy-Efficient Embedded Systems for Sustainable Digital Infrastructure

Deep technical workflows for low-power embedded systems, TinyML endpoints, Linux edge nodes, and PYNQ-assisted adaptive acceleration.

## Included workflows

- Python:
  - duty-cycle and TinyML endpoint energy modeling
  - edge compute budget comparison
- R:
  - fleet lifecycle and maintenance-burden analysis
- C:
  - event-driven Cortex-M low-power firmware example
- C++:
  - TinyML endpoint inference skeleton
- Bash:
  - Linux CPUFreq and scheduler inspection snippets
- SQL:
  - optional fleet/deployment registry schema
- Docs:
  - implementation notes and workload-tier guidance
