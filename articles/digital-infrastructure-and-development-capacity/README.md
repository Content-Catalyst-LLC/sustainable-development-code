# Digital Infrastructure and Development Capacity

Advanced code workflows for the article on digital infrastructure and development capacity.

## Included workflows

- Python:
  - digital public infrastructure readiness scoring
  - interoperability, resilience, and lock-in diagnostics
  - service-delivery pathway and institutional capability analysis
- R:
  - cross-country digital-capacity summaries
  - digital divide and territorial exclusion analysis
- SQL:
  - identity registry
  - payments and service-delivery logs
  - interoperability and resilience dashboards
  - access-control and event tracking
- Go:
  - lightweight digital-capacity scoring service
- Rust:
  - validation utility for registry and event records
- Embedded C:
  - optional low-resource offline service node
- C++:
  - optional local interoperability and uptime scoring

## Folder layout

- `python/`: scoring, diagnostics, and scenario workflows
- `r/`: comparative summaries and exclusion analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional embedded/offline service logic
- `cpp/`: optional local interoperability scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: notes and implementation guidance
