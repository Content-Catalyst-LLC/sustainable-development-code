# What Is Sustainable Development? Meaning, Systems, and Long-Run Viability

Advanced code workflows for the article on sustainable development, systems, and long-run viability.

## Included workflows

- Python:
  - sustainable-development and long-run-viability risk scoring
  - systems, burden, and governance diagnostics
- R:
  - cross-region and cross-territory sustainable-development summaries
  - ecological constraint, long-run viability, and governance-risk analysis
- SQL:
  - sustainable-development registry
  - viability, governance, and burden logs
  - sustainable-development dashboards
- Go:
  - lightweight sustainable-development risk scoring service
- Rust:
  - validation utility for sustainable-development records
- Embedded C:
  - optional low-resource viability signal node
- C++:
  - optional local sustainable-development risk scorer
