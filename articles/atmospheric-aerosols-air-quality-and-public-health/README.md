# Atmospheric Aerosols, Air Quality, and Public Health

Advanced code workflows for the article on atmospheric aerosols, air quality, and public health.

## Included workflows

- Python:
  - aerosol exposure and public-health burden scoring
  - inequality, governance, and monitoring diagnostics
- R:
  - cross-region and cross-territory air-quality summaries
  - inequality and systemic-burden analysis
- SQL:
  - aerosol-burden registry
  - exposure, monitoring, and mitigation logs
  - public-health and inequality dashboards
- Go:
  - lightweight aerosol-burden scoring service
- Rust:
  - validation utility for aerosol and air-quality records
- Embedded C:
  - optional low-resource air-quality signal node
- C++:
  - optional local aerosol-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and inequality analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional air-quality signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
