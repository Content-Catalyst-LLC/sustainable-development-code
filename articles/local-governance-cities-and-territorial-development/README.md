# Local Governance, Cities, and Territorial Development

Advanced code workflows for the article on local governance, cities, and territorial development.

## Included workflows

- Python:
  - territorial governance and urban capacity scoring
  - fragmentation, resilience, and implementation diagnostics
- R:
  - cross-country and cross-territory governance summaries
  - spatial justice and service-reach analysis
- SQL:
  - territorial governance registry
  - service, land, and resilience logs
  - spatial justice and fragmentation dashboards
- Go:
  - lightweight territorial-governance scoring service
- Rust:
  - validation utility for local-governance records
- Embedded C:
  - optional low-resource urban-service signal node
- C++:
  - optional local territorial-risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and spatial analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional urban-service signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
