# Debt, Fiscal Space, and Development Constraints

This module contains the code workflows referenced in the article on debt, fiscal space, and development constraints.

## Included workflows

- Python: debt-service burden scoring, fiscal-space estimation, refinancing risk, and crowding-out diagnostics
- R: cross-country debt summaries, expenditure compression analysis, and vulnerability comparison
- SQL: sovereign debt registry, creditor composition, repayment schedules, and dashboard views
- Go: lightweight fiscal-space scoring service
- Rust: validation utility for debt records and repayment schedules
- Embedded C: optional low-resource fiscal reporting stub
- C++: optional local debt-alert and sustainability-threshold scoring

## Folder layout

- `python/`: scoring, diagnostics, and scenario tools
- `r/`: comparative summaries and reporting analysis
- `sql/`: schema, schedules, logs, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight scoring service
- `c/`: optional embedded reporting logic
- `cpp/`: optional local debt-alert scoring
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
