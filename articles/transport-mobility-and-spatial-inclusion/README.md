# Transport, Mobility, and Spatial Inclusion

Advanced code workflows for the article on transport, mobility, and spatial inclusion.

## Included workflows

- Python:
  - accessibility and opportunity-reach scoring
  - safety, affordability, and car-dependence diagnostics
  - territorial connectivity and climate-aware mobility analysis
- R:
  - cross-region mobility burden summaries
  - subgroup and territorial exclusion analysis
- SQL:
  - route, stop, fare, and service registries
  - accessibility and safety logs
  - territorial connection dashboards
- Go:
  - lightweight accessibility and travel-burden scoring service
- Rust:
  - validation utility for route, fare, stop, and service records
- Embedded C:
  - optional low-resource transport-monitoring node
- C++:
  - optional local fleet/service quality and accessibility scoring

## Folder layout

- `python/`: scoring, diagnostics, and scenario workflows
- `r/`: comparative summaries and exclusion analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional embedded transport-monitoring logic
- `cpp/`: optional local service-quality scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: notes and implementation guidance
