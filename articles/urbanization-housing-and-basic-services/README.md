# Urbanization, Housing, and Basic Services

Advanced code workflows for the article on urbanization, housing, and basic services.

## Included workflows

- Python:
  - urbanization, housing, and service-risk scoring
  - housing-gap and service-fragility diagnostics
- R:
  - cross-region and cross-territory urban summaries
  - housing inequality and governance gap analysis
- SQL:
  - urban-risk registry
  - housing, services, and governance logs
  - settlement dashboards
- Go:
  - lightweight urban-risk scoring service
- Rust:
  - validation utility for housing and service-risk records
- Embedded C:
  - optional low-resource service signal node
- C++:
  - optional local urban-risk scorer
