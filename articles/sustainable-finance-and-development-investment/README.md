# Sustainable Finance and Development Investment

Advanced code workflows for the article on sustainable finance and development investment.

## Included workflows

- Python:
  - sustainable finance allocation scoring
  - blended finance leverage and de-risking diagnostics
  - adaptation/mitigation allocation and development-gap scoring
- R:
  - cross-country financing-gap summaries
  - inclusion, SME finance, and uneven access analysis
- SQL:
  - project registry
  - sustainable bond issuance
  - blended finance instruments
  - taxonomy and disclosure tracking
  - dashboard views
- Go:
  - lightweight sustainable-investment scoring service
- Rust:
  - validation utility for project and disclosure records
- Embedded C:
  - optional low-resource reporting stub
- C++:
  - optional local project-eligibility and resilience scoring

## Folder layout

- `python/`: scoring, diagnostics, and scenario workflows
- `r/`: comparative summaries and access analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional embedded reporting logic
- `cpp/`: optional local eligibility scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: notes and implementation guidance
