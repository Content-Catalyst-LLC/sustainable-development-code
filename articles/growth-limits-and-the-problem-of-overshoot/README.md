# Growth, Limits, and the Problem of Overshoot

Advanced code workflows for the article on growth, limits, and the problem of overshoot.

## Included workflows

- Python:
  - overshoot-risk and viability scoring
  - throughput-pressure and delay diagnostics
- R:
  - cross-region and cross-territory overshoot summaries
  - throughput, delay, and governance-risk analysis
- SQL:
  - overshoot registry
  - throughput, delay, and governance logs
  - overshoot dashboards
- Go:
  - lightweight overshoot-risk scoring service
- Rust:
  - validation utility for overshoot-risk records
- Embedded C:
  - optional low-resource throughput signal node
- C++:
  - optional local overshoot-risk scorer
