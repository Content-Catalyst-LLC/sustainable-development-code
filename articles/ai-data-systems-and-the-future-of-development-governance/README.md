# AI, Data Systems, and the Future of Development Governance

This module contains the code workflows referenced in the article on AI, data systems, and development governance.

## Included workflows

- Python: public-sector AI project scoring, readiness, governance risk, and deployment recommendation logic
- R: country-level and longitudinal governance readiness analysis
- SQL: dashboard and audit-oriented schema for AI governance reporting
- Rust: validation utility for AI governance project intake records

## Folder layout

- `python/`: project scoring and governance analysis
- `r/`: longitudinal comparative reporting
- `sql/`: schema, views, and audit queries
- `rust/`: typed validation tooling
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
