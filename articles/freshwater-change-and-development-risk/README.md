# Freshwater Change and Development Risk

This repository folder supports the article **"Freshwater Change and Development Risk."**

It provides reproducible code scaffolding for analyzing freshwater change as a development-risk problem rather than a narrow water-supply problem. The workflows model streamflow stress, soil-moisture stress, water-quality burden, wastewater-treatment deficit, freshwater-ecosystem decline, food and livelihood dependence, health and sanitation exposure, governance capacity, and monitoring readiness.

## Contents

- `python/freshwater_change_risk.py` — freshwater-development risk scoring
- `r/hydrological_exposure_analysis.R` — hydrological exposure and governance gap analysis
- `sql/freshwater_change_schema.sql` — relational schema and diagnostic scoring queries
- `rust/freshwater_risk_score.rs` — lightweight infrastructure-oriented scoring utility
- `data/freshwater_change_panel.csv` — example freshwater indicator dataset
- `docs/` — setup, data model, and methodology notes

## Core Concept

Freshwater change should be treated as a development-risk framework. The goal is not only to ask whether enough water exists somewhere in the system, but whether hydrological conditions remain stable, safe, usable, and ecologically functional enough to support human capability, public health, food systems, ecosystems, and long-run resilience.
