# Development Under Deep Uncertainty

This module contains the code workflows referenced in the article on development under deep uncertainty.

## Included workflows

- Python: scenario stress-testing, regret analysis, and robustness scoring
- R: adaptive capacity and robustness panel analysis
- SQL: scenario registry and longitudinal robustness dashboard logic
- Rust: validation utility for scenario input records
- Go: lightweight pathway evaluation service for multi-future planning

## Folder layout

- `python/`: stress-testing and robustness scoring workflows
- `r/`: comparative panel and adaptive-capacity analysis
- `sql/`: schema and robustness query logic
- `rust/`: typed validation tooling
- `go/`: lightweight scenario evaluation service
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
