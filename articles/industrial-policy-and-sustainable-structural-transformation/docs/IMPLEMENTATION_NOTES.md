# Implementation Notes

This module is designed around five linked industrial-policy questions:

1. Which sectors have the strongest transition and upgrading potential?
2. Where do productive capabilities remain too shallow for durable transformation?
3. How does green transition readiness interact with lock-in risk?
4. Which regions face the largest territorial industrial-transition constraints?
5. How can policy-support instruments, standards, and ecosystem conditions be tracked together?

Suggested workflow:
- Validate raw CSVs with Rust.
- Run Python scoring pipelines.
- Run R comparative and territorial analysis.
- Use SQL tables and views to maintain ecosystem, standards, and policy-support registries.
- Use Go for lightweight sector scoring integration.
