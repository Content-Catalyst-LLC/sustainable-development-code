# Risk, Shock, and Fragility in Development Systems

This module contains the code workflows referenced in the article on risk, shock, and fragility in development systems.

## Included workflows

- Python: shock exposure, resilience, and fragility scoring
- R: multidimensional fragility and shock-burden analysis
- SQL: fragility registry, shock event logs, and dashboard views
- Rust: validation utility for fragility input records
- Go: lightweight fragility evaluation service
- Embedded C: low-level infrastructure shock monitoring logic
- C++: edge-side resilience and infrastructure brittleness scoring

## Folder layout

- `python/`: fragility scoring and risk analysis
- `r/`: comparative and longitudinal fragility analysis
- `sql/`: schema, event logs, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight fragility evaluation service
- `c/`: embedded monitoring and threshold logic
- `cpp/`: edge resilience and brittleness scoring
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
