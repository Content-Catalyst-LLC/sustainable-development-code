# Health, Education, and Human Capability Expansion

Advanced code workflows for the article on health, education, and human capability expansion.

## Included workflows

- Python:
  - health, education, and capability risk scoring
  - service-quality and access diagnostics
- R:
  - cross-region and cross-territory capability summaries
  - capability-gap and governance-risk analysis
- SQL:
  - capability-risk registry
  - health, education, and governance logs
  - capability dashboards
- Go:
  - lightweight capability-risk scoring service
- Rust:
  - validation utility for capability-risk records
- Embedded C:
  - optional low-resource capability signal node
- C++:
  - optional local capability-risk scorer
