# Resilience Thinking and Sustainable Development

This module contains the code workflows referenced in the article on resilience thinking and sustainable development.

## Included workflows

- Python: adaptive capacity, disturbance response, and resilience scoring
- R: social-ecological resilience and adaptive governance analysis
- SQL: resilience registry, disturbance logs, and dashboard views
- Rust: validation utility for resilience input records
- Go: lightweight resilience evaluation service
- Embedded C: low-level infrastructure disturbance monitoring
- C++: edge-side resilience and brittleness scoring

## Folder layout

- `python/`: resilience scoring and systems analysis
- `r/`: comparative and longitudinal resilience analysis
- `sql/`: schema, disturbance logs, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight resilience evaluation service
- `c/`: embedded monitoring and threshold logic
- `cpp/`: edge resilience and brittleness scoring
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
