# Anthropocene and Planetary Boundaries

Advanced code workflows for the article on Earth-system risk, planetary boundaries, and sustainable development.

## Included workflows

- Python:
  - planetary-boundary risk scoring
  - Earth-system pressure diagnostics
- R:
  - cross-region and cross-territory planetary-pressure summaries
  - boundary transgression and governance-capacity analysis
- SQL:
  - planetary-risk registry
  - Earth-system pressure and governance logs
  - planetary-boundary dashboards
- Go:
  - lightweight planetary-risk scoring service
- Rust:
  - validation utility for planetary-risk records
- Embedded C:
  - optional low-resource Earth-system signal node
- C++:
  - optional local planetary-risk scorer
