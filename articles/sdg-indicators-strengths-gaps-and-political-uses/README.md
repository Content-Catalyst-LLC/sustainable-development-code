# SDG Indicators: Strengths, Gaps, and Political Uses

This module contains the code workflows referenced in the article on SDG indicators, their methodological strengths and weaknesses, and their political and institutional uses.

## Included workflows

- Python: indicator normalization, distance-to-target scoring, and SDG performance gap analysis
- R: disaggregation, inequality-gap, and indicator visibility analysis
- SQL: indicator registry, metadata logs, and reporting dashboard views
- Rust: validation utility for indicator input records
- Go: lightweight SDG scoring service
- Embedded C: low-level edge reporting stub for indicator collection logic
- C++: edge-side indicator quality and completeness scoring

## Folder layout

- `python/`: normalization, target-distance scoring, and diagnostics
- `r/`: disaggregation and subgroup gap analysis
- `sql/`: schema, metadata logs, and dashboard views
- `rust/`: typed validation tooling
- `go/`: lightweight SDG scoring service
- `c/`: embedded data collection / reporting logic
- `cpp/`: edge data-quality and completeness scoring
- `data/raw/`: source datasets
- `data/processed/`: generated outputs
- `outputs/`: notes and exported artifacts
