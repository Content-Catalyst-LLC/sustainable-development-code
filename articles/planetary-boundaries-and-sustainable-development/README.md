# Planetary Boundaries and Sustainable Development

Advanced code workflows for the article on planetary boundaries and sustainable development.

## Included workflows

- Python:
  - planetary boundaries and development risk scoring
  - governance, transition, and exposure diagnostics
- R:
  - cross-region and cross-territory planetary summaries
  - burden, exposure, and governance gap analysis
- SQL:
  - planetary-risk registry
  - boundary, burden, and governance logs
  - transition dashboards
- Go:
  - lightweight planetary-risk scoring service
- Rust:
  - validation utility for planetary-boundary and development-risk records
- Embedded C:
  - optional low-resource Earth-system signal node
- C++:
  - optional local planetary-risk scorer
