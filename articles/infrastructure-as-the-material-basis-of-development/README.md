# Infrastructure as the Material Basis of Development

Advanced code workflows for the article on infrastructure as the material basis of development.

## Included workflows

- Python:
  - infrastructure access and capability scoring
  - resilience, maintenance, and climate-risk diagnostics
  - lock-in and pathway scenario analysis
- R:
  - cross-country and regional infrastructure inequality summaries
  - territorial and subgroup access analysis
- SQL:
  - infrastructure asset registry
  - maintenance, outage, and inspection logs
  - service access and resilience dashboards
- Go:
  - lightweight infrastructure readiness and resilience scoring service
- Rust:
  - validation utility for asset, maintenance, and service records
- Embedded C:
  - optional low-resource infrastructure monitoring node
- C++:
  - optional local infrastructure quality and resilience scoring

## Folder layout

- `python/`: scoring, diagnostics, and scenario workflows
- `r/`: comparative summaries and exclusion analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional embedded infrastructure-monitoring logic
- `cpp/`: optional local resilience scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: notes and implementation guidance
