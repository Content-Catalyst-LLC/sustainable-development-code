# Intergenerational Justice and Long-Term Stewardship

Advanced code workflows for the article on intergenerational justice and long-term stewardship.

## Included workflows

- Python:
  - intergenerational justice and stewardship risk scoring
  - burden-transfer and institutional-stewardship diagnostics
- R:
  - cross-region and cross-territory intergenerational summaries
  - future-burden transfer, stewardship capacity, and governance-risk analysis
- SQL:
  - intergenerational-justice registry
  - stewardship, burden-transfer, and governance logs
  - long-horizon dashboards
- Go:
  - lightweight intergenerational-risk scoring service
- Rust:
  - validation utility for intergenerational-risk records
- Embedded C:
  - optional low-resource future-burden signal node
- C++:
  - optional local stewardship-risk scorer
