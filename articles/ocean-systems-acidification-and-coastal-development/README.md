# Ocean Systems, Acidification, and Coastal Development

Advanced code workflows for the article on ocean systems, acidification, and coastal development.

## Included workflows

- Python:
  - ocean acidification and coastal development risk scoring
  - marine dependence, governance, and monitoring diagnostics
- R:
  - cross-region and cross-coastal-type ocean-risk summaries
  - coastal exposure and compound marine-risk analysis
- SQL:
  - coastal-ocean risk registry
  - monitoring, dependence, and governance logs
  - marine habitability and justice dashboards
- Go:
  - lightweight coastal-ocean risk scoring service
- Rust:
  - validation utility for ocean and coastal risk records
- Embedded C:
  - optional low-resource ocean-monitoring signal node
- C++:
  - optional local coastal-ocean risk scorer

## Folder layout

- `python/`: scoring and diagnostic workflows
- `r/`: comparative summaries and exposure analysis
- `sql/`: schema, registries, logs, and dashboards
- `go/`: lightweight scoring service
- `rust/`: typed validation tooling
- `c/`: optional ocean-monitoring signal logic
- `cpp/`: optional local risk scoring
- `data/raw/`: source datasets
- `data/processed/`: transformed datasets
- `outputs/`: exported summaries
- `docs/`: implementation notes
